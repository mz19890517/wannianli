# 万年历 (Wannianli)

一个简单的 Android 万年历应用,含农历、干支、节气和黄历(宜忌/冲煞)。

## 功能

- 月视图网格,支持前后月份切换与"回到今天"
- 每天显示农历日期、公历/农历节日、节气
- 点击任意日期查看详情:公历、农历、干支年月日、黄历值神/宜忌/冲煞

## 数据范围与精度

- 农历支持 1900-2100 年
- 节气按天文近似算法推算
- 黄历为基于建除十二神的简化推导,仅供参考

## 构建

仓库配置了 GitHub Actions,推送到 `main` 分支后自动构建 APK:
- 在仓库的 **Actions** 页面查看构建状态
- 构建完成后到对应运行记录里下载 `wannianli-debug` / `wannianli-release` 构件

release 版本使用 debug 签名,可直接安装测试。
